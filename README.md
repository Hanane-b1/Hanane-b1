## Hanane Belhadi

**Développeuse full stack · Laravel et React · Casablanca**

Je conçois et développe des applications web complètes, de la base de données et de l'API Laravel jusqu'à l'interface React.

Pendant mon stage chez Groupe Vitalys Santé, j'ai développé ClinArchi, une plateforme qui génère le plan architectural et le programme des surfaces d'une clinique à partir de quelques paramètres.

Formée à l'ISGI Casablanca (Technicienne Spécialisée en Développement Full Stack). Disponible pour un poste de développeuse junior ou des missions freelance.
